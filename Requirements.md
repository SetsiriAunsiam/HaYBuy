# 🤖 AI Agent Instruction: HaYBuy Marketplace App

## 📋 Project Context
You are an AI assistant helping to build **HaYBuy**, a local community marketplace mobile application.  
The project uses **Flutter/Dart (frontend)** and **Firebase (backend)**.  
Your role is to guide, generate, and support development tasks across all milestones.

---

## 🎯 Objectives
- Build a fully functional local marketplace app for **Hat Yai community**.
- Ensure **code quality, maintainability, and scalability**.
- Provide **mock data, testing scenarios, and documentation**.
- Assist with **UI/UX design, debugging, and optimization**.

---

## 🚀 Core Features
1. **User Registration & Verification**
   - Firebase Auth (sign-up/login).
   - Location-based verification.
   - User profiles: name, photo, contact info, address.
   - Mock ID verification.

2. **Item Listing**
   - Add/edit/delete listings with images (camera/gallery).
   - Categories: electronics, clothing, books, etc.
   - Fields: price, condition, description.
   - Status: available, sold, reserved.

3. **Advanced Search & Filtering**
   - Keyword search.
   - Filter by category, price, distance.
   - Sort by price, date, distance.
   - Map-based search (Google Maps/OpenStreetMap).
   - Save favorite searches.

4. **In-app Messaging**
   - Firebase Realtime Database chat.
   - Image sharing.
   - Message read receipts.
   - Price negotiation support.
   - Chat list display.

5. **Rating & Review System**
   - 1–5 star ratings.
   - Written reviews.
   - User rating & history.
   - Reputation score calculation.
   - Report inappropriate behavior.

6. **Push Notifications**
   - New messages.
   - Item interest alerts.
   - New items in interested categories.
   - Price update alerts.

7. **Saved Items & Wishlist**
   - Save items of interest.
   - Wanted list.
   - Track price changes.
   - Share wishlists.

8. **Transaction History & Offline Access**
   - Buy/sell history.
   - Transaction statistics.
   - Offline saved items (SharedPreferences / SQLite).
   - Sync when online.

---

## 🛠️ Tech Requirements
- **Frontend**: Flutter/Dart.
- **Backend**: Firebase (Auth, Firestore, Storage, FCM, Realtime DB).
- **State Management**: Provider or Riverpod.
- **Local Storage**: `SharedPreferences` / `sqflite`.
- **Image Handling**: `image_picker`, `cached_network_image`.
- **Mapping**: Google Maps API / OpenStreetMap.
- **Location Services**: `geolocator`.
- **Mock Data**: Categories, items, users, reviews, Hat Yai location coords.
- **Security**: Image verification, hidden sensitive data, reporting system.
